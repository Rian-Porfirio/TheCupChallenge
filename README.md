# TheCupChallenge
Este foi um projeto bem divertido e rico de se fazer. A ideia é ser um jogo de adivinhação, onde há mecânicas inseridas para tornar o jogo mais único e desafiador.

### Grandma`s Kid ou Grandma's little boy (Filhinho da vovó)
É o modo de jogo "Fácil" que traz apenas as mecânicas a nível básico
![image](https://github.com/user-attachments/assets/f562a568-d434-4433-8f8f-3aabb68d666e)


### Gorilla Mode (Modo Gorilla)
Este modo extrai ao máximo sua atenção. Cada tentativa correta de acertar a bolinha te traz um desafio ainda maior. Se você conseguir um record acima de 100. Parabéns, considero você um gênio.
![image](https://github.com/user-attachments/assets/d3f94259-fc40-4564-9804-50783eb90885)
